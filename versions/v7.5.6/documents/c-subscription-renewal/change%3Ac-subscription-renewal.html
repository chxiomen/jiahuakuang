页面入口

  • 点击「我的」会员卡片进入
  • 用户成功购买连续商品并收到支付成功通知后，返回小程序时自动进入

会员卡片

  • 展示当前会员昵称
  • 展示会员类型和当前订阅商品，例如：VIP会员 · 连续包月
  • 展示用户ID

下次扣费信息

  • 展示下次续费时间、下次续费金额
  • 需与用户实际购买的连续商品保持一致
  • 连续包月：下次扣费时间为首次付费日期 + 31天
  • 连续包年：下次扣费时间为首次付费日期 + 372天（12×31天）
  • 按固定天数累加，不按月末调整

服务承诺

  • 展示安全无忧：扣费前发送扣费通知
  • 展示扣费透明：用户可以查询扣费记录
  • 展示随时取消：用户可以按照指引取消自动续费

扣费记录

  • 按时间倒序展示历史扣费记录
  • 每条记录展示订阅商品名称，例如：VIP连续包月
  • 展示本次扣费金额
  • 展示本次订阅对应的有效期起止时间
  • 扣费记录以服务端实际支付结果为准，不能仅根据客户端展示生成

取消续费

  • 页面需要明确告知用户：取消自动续费需要前往微信操作
  • 展示取消路径：微信 → 我 → 服务 → 钱包 → 支付设置 → 自动续费
  • 用户取消成功后，不再产生下一次自动扣费，但当前已购买的会员权益仍可使用至有效期结束
  • 用户取消自动续费后，可以重新进入付费页购买其他商品

续费状态展示

  • 正常续费中：展示当前会员、订阅商品、下次续费时间和金额，并提供取消续费指引
  • 已取消续费但权益仍有效：展示已取消自动续费状态、会员权益到期时间，并明确不会再次扣费
  • 已取消续费但权益仍有效时，用户仍可正常使用会员权益
  • 会员已到期：展示权益已结束提示，不展示下次扣费信息，并提供立即续费入口
  • 自动续费状态下不提供重复进入付费页购买的入口；取消后可以重新购买其他商品

状态变更与数据来源

  • 取消续费成功后，服务端更新自动续费状态，客户端返回小程序时刷新会员状态
  • 客户端不得仅根据用户点击取消按钮就判定取消成功，必须等待服务端或微信支付结果确认
  • 续费状态、权益到期时间、下次扣费时间和金额均以服务端数据为准
  • 会员中心、我的页面和续费管理页的状态需要保持一致

使用问题与客服

  • 页面提供售后客服入口
  • 用户遇到使用体验、退款或扣费问题时，可以联系客服
  • 客服处理时需要能够关联用户ID、订阅商品、扣费金额和扣费时间

支付结果与异常状态

  • 支付成功：刷新会员状态，并在用户返回小程序时关闭付费页，自动进入续费管理页
  • 支付失败：用户停留在付费页，不进入续费管理页
  • 自动续费扣款失败：保留当前扣款结果和失败提示，并引导用户联系客服或重新购买
  • 续费管理页展示的信息以服务端会员状态和支付回调结果为准
