# 加画框 Figma UI 规范

适用范围：本工作区中由 Codex 新建或修改的 Figma 设计稿。用户当次明确指定的设计要求优先。

## 文本

- 本次新建或编辑的文本图层，其垂直对齐设为 **Align middle**，对应 Figma 属性 `textAlignVertical = 'CENTER'`。在设定文本框高度后再次确认该属性。
- 只有源设计明确要求文本从顶部开始排布的多行文本框，才使用 Align top，并在交付说明中指出例外。
- 文案、字号、字重、斜体、字距、行高与颜色以最终渲染的原型或用户提供的参照图为准。不凭记忆补写文案。

## 结构与素材

- 文字、控件和图形尽量保留为可编辑图层；使用原型已有的图形素材，保留有意设计的渐变、透明度和异形轮廓。
- 成组内容按源页面的父子关系组织。控件和标签的对齐关系应由布局容器表达。

## 验收

- 用相同逻辑尺寸对照原型和 Figma，逐项检查文本框、图标、水印、控件和间距。
- 源字体不可用时，记录替代字体以及仍存在的视觉差异。
- 网页原型同步的具体步骤见 [FIGMA_SYNC_CHECKLIST.md](FIGMA_SYNC_CHECKLIST.md)。

尚未指定统一的品牌字号、色板、间距和圆角数值；复刻任务以对应页面的最终渲染值为准，后续可在本文件中补充。
